## ANIMATION TYPES - Color & Hover Effects

### BEFORE (Current - Grayscale):
```
┌────────────────┐              ┌────────────────┐
│ Image (Gray)   │   HOVER   →  │ Image (Color)  │
│ scale: 1.0     │     →        │ scale: 1.0     │
│ opacity: 100%  │     →        │ opacity: 100%  │
└────────────────┘              └────────────────┘
```

### AFTER (New - Always Color):
```
┌────────────────┐              ┌────────────────┐
│ Image (Color)  │   HOVER   →  │ Image (Bright) │
│ scale: 1.0     │     →        │ scale: 1.05    │
│ brightness:100%│     →        │ brightness:115%│
│ shadow: small  │     →        │ shadow: large  │
└────────────────┘              └────────────────┘
Duration: 0.4-0.5s (smooth)
```

---

## ANIMATION TIMING

**Scroll Entrance**:
- Fade: 0% → 100% opacity
- Scale: 0.95 → 1.0
- Duration: 0.8-1.2 seconds
- Easing: power3.out (natural deceleration)

**Hover Effect**:
- Scale: 1.0 → 1.05 (5% zoom)
- Brightness: 100% → 115%
- Shadow: Small → Large glow
- Duration: 0.4-0.5 seconds

**Stagger**:
- Items: 0.1-0.15 seconds between each
- Creates visual rhythm

**Parallax**:
- Speed: 0.3-0.5 (slower than scroll)
- Creates depth sensation
